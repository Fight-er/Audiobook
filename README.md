# 有声书 · Audiobook Reader

一个跑在本机的**有声书阅读器 + 离线语音书生成器**。导入 `.txt` / `.md` / `.epub`，
阅读时逐段高亮朗读；点一下就能把整章（或整本）书用本机 **Voicebox / Qwen3-TTS** 合成成音频，
音频存在浏览器本地数据库里 —— **一次生成，永久离线可听**。

```
┌──────────────────────────── 浏览器 ────────────────────────────┐
│  阅读器 UI (原生 ES Module, 零构建)                            │
│   ├─ parser.js     txt/epub → 章节 → 段落 → 朗读块(≤220字)      │
│   ├─ generator.js  生成队列：逐块合成 / 暂停 / 续传 / 重试      │
│   ├─ player.js     章节时间轴播放、变速保调、跨块无缝、自动连播 │
│   ├─ store.js      IndexedDB：书、章节、音频 Blob、进度、设置   │
│   └─ export.js     多段 WAV → 单文件 WAV（裸 PCM 拼接）         │
│  Service Worker 缓存整个界面 → 断网也能打开                     │
└───────────────────────────────┬────────────────────────────────┘
                                │  /api/*（同源代理，绕开 CORS）
┌───────────────────────────────▼────────────────────────────────┐
│  server.mjs  (Node ≥18, 零依赖)  :5178                          │
└───────────────────────────────┬────────────────────────────────┘
                                │  HTTP
┌───────────────────────────────▼────────────────────────────────┐
│  Voicebox 本机 TTS  :17493   (Qwen3-TTS / 音色克隆)             │
└────────────────────────────────────────────────────────────────┘
```

## 快速开始

```bat
:: 1) 确保 Voicebox 桌面应用已启动（http://127.0.0.1:17493/docs 能打开）
:: 2) 启动阅读器
start.cmd
::    或
node server.mjs
```

打开 <http://127.0.0.1:5178/>，左侧「导入书籍」，然后点顶栏「生成本章」。

想先试试手？`samples/` 目录里有示例书：`星海拾遗.txt`（纯文本）和 `星海拾遗.epub`（EPUB）。

> 需要 Node.js ≥ 18（不需要 `npm install`，服务端零依赖）。

## 功能

**阅读**
- 自动分章：识别「第X章 / Chapter N / 序章 / 楔子 …」；没有标题时按字数自动切分
- 自动分段：兼容中文小说（一行一段）与英文排版（空行分段）
- **脚注对照**：正文里的 `[1]`、`［2］` 这类序号不会朗读，而是变成可点击角标；
  点角标 → 右侧注释栏定位到条目，点条目 → 跳回正文位置；播放到含注释的段落时该条自动高亮
- **智能分段**：散文一段一块；史诗 / 诗歌这类一行一行的排版会自动**跨行合并成整句**再合成，
  避免「一行一停」的碎读（实测《伊利亚特》622 行 → 106 段，平均 111 字，98% 在句末断开）
- 章节内朗读块高亮跟随、点击任意段落从该处开始播放
- **七套配色**：羊皮纸 / 牛皮纸 / 纸白 / 浅灰 / 护眼绿 / 夜读 / 纯黑，纸质主题带极淡的纸纤维底纹，
  设置里点色卡即时预览、取消可回滚
- 字号可调、阅读进度自动记忆

**离线语音书生成**
- 逐块合成、实时进度、剩余时间估算；可**暂停 / 继续 / 停止**，关掉页面再回来可**断点续传**
- 单块失败自动重试 3 次，仍失败只跳过该块、不阻塞整章，之后可再次点击补齐
- 「整本生成」会排队处理所有未完成章节
- 音色（Voicebox 语音档案）、引擎、模型规模、朗读语言、风格提示均可选

**播放**
- 章节整段时间轴：进度条拖动、±15 秒、块间无缝推进、自动连播下一章
- 0.75×–2.5× 变速**保持音调**（不变声）
- 定时停止（15/30/45/60 分钟）、键盘快捷键

**离线**
- 音频以 WAV Blob 存于 IndexedDB，关掉 Voicebox、断网后已配音章节照常播放
- Service Worker 缓存界面外壳，离线也能打开页面

**导出**
- 「导出」把本章所有音频拼成一个 WAV 直接下载（裸 PCM 拼接，不重编码、不损音质）
- 需要 MP3 可用 ffmpeg / VLC 转换：`ffmpeg -i 章节.wav -b:a 96k 章节.mp3`

## 重新生成语音

生成过的段落默认会被跳过（避免重复烧 GPU）。要换音色/引擎重做，有四条路径：

| 方式 | 位置 | 作用范围 |
| --- | --- | --- |
| 章节头「重新生成」按钮 | 阅读区标题下方（已配音时出现） | 本章全部段落 |
| `⋯` 菜单 | 顶栏右侧 | 重新生成本章 / 重新生成整本 / 清除本章音频 |
| 右键任意段落 | 正文里右键 | 只重生成这一段、或从这里往后补齐 |
| `Shift + R` | 键盘 | 重新生成当前章节 |

细节：
- 重新生成会先删除对应的本地音频，再用**当前设置**的（音色 / 引擎 / 模型 / 语言）重新合成
- 每段都会记录生成时用的参数；如果之后换了音色，章节头会出现「N 段音色不一致 · 重新生成」提示，点一下即可批量更新
- 「清除本章音频」只删音频、保留文字与笔记，用于释放空间
- 所有重新生成同样支持暂停 / 续传 / 取消

## 用到的 Voicebox 接口

| 用途 | 接口 |
| --- | --- |
| 连接状态 | `GET /health` |
| 音色列表 | `GET /profiles` |
| 模型状态 | `GET /models/status` |
| 提交合成 | `POST /generate` → `{ id, status:"generating" }` |
| 轮询进度 | `GET /history/{id}` （也支持 `GET /generate/{id}/status` 的 SSE） |
| 取音频 | `GET /audio/{id}`（WAV） |
| 取消 | `POST /generate/{id}/cancel` |

请求体关键字段：`profile_id`、`text`、`language`、`engine`、`model_size`、`instruct`、
`max_chunk_chars`、`normalize`。

> **为什么要代理？** Voicebox 不发送 `Access-Control-Allow-Origin`，浏览器无法跨端口直接调用；
> `server.mjs` 把 `/api/*` 转发到 `http://127.0.0.1:17493`，前端就能同源访问。
> 想指向别的地址：`set VOICEBOX_URL=http://127.0.0.1:9000` 后再启动。

## 常见问题

**生成卡在「正在加载语音模型」很久？**
首次生成要把模型读进显存。若显存被其他程序（浏览器、游戏、聊天软件）占用过多，
1.7B 模型可能装不下并被换页到共享内存，导致极慢。可：
1. 关掉占显存的程序后重试；
2. 在「设置 → 模型规模」改用 **0.6B**（Voicebox 会自动下载约 1.7GB）；
3. 或改用 `kokoro` / `luxtts` 等轻量引擎（CPU 也能跑）。

**页面提示「语音服务离线」？**
Voicebox 桌面应用没启动。启动后页面每 60 秒自动重连；已生成的音频不受影响。

**音频占多少磁盘？**
Voicebox 输出 24kHz 单声道 16bit WAV ≈ **2.9 MB/分钟**、约 170 MB/小时。
阅读器会在设置里显示本地占用；删除书籍会连带删除其音频。

**换「每段字数」会怎样？**
只在尚未生成音频的章节重新分块；已有音频的章节保持不变。

## 升级说明

旧版本导入的书籍会在第一次打开章节时自动升级：重新抽取脚注、按新规则重新分块。
如果该章**已经生成过音频**，为了不让音频错位，会保留原来的分段，只清理文字。

EPUB 的诗节空行需要重新解析才能恢复——如果是旧版本导入的史诗类书籍，建议
删掉该书后重新导入一次，即可获得诗节间距与跨行合并的最佳效果。

## 多节点并行生成

可以在多台机器上各跑一个 Voicebox，阅读器会**同时把任务分给它们**：

```
主机 A (4060 Ti)  ─┐
                   ├─ 共享任务队列 → 谁空闲谁取下一段（约快一倍）
主机 B (2060)     ─┘
```

- 节点配置存在项目根目录的 `backends.json`，也可以在「设置 → 语音服务节点」里增删、勾选、重新检测
- 每个节点状态实时显示（如 `18ms` / `离线`）；某台掉线会自动把它没做完的任务交回队列
- 局域网节点只需要那台机器开着 Voicebox，并且防火墙放行 `17493`

默认配置（本机 + 局域网各一台）：

```json
{
  "backends": [
    { "id": "local", "label": "本机 · 4060Ti", "url": "http://127.0.0.1:17493" },
    { "id": "lan",   "label": "局域网 · 192.168.18.33", "url": "http://192.168.18.33:17493" }
  ]
}
```

代理路径：`/api/*` → 默认节点，`/b/<id>/*` → 对应节点。

## 多个音色版本

同一本书可以保存**多份不同音色的朗读**，互不覆盖：

- 顶栏「音色」按钮 → 切换版本 / 新建版本 / 删除当前版本
- 每个版本独立记录（音色档案、引擎、模型、语言）与独立音频，切换后阅读器立即换成那一版的声音
- 新建版本相当于给这本书开一条新的音轨：从零开始生成，随时切回旧版本对比
- 老数据自动迁移：旧书会补一个「默认音色」版本，原有音频归到该版本下，不会丢


### 节点音色自动对应

每台机器的 Voicebox 有自己的音色库，**同一个声音在不同机器上的 profile id 不一样**
（例如都叫「1」：本机 `461823ef-…`，局域网 `99c30d93-…`）。
生成时会按下面顺序为每个节点解析出可用的音色：

1. 同 ID
2. **同名**（最常用：两台机器导入的是同一个音色）
3. 设置里手动指定的「节点音色」
4. 该节点上的第一个音色

「设置 → 语音服务节点」里每行右侧会显示该节点实际使用的音色，可手动切换；
解析不到音色（该节点一个音色都没有）会自动跳过并在提示里说明。
每段音频也会记录实际使用的节点音色，方便排查。


### 目录与注释的适配

- **按 EPUB 自带目录解析**：优先读 `toc.ncx`，其次 EPUB3 nav 文档；标题用目录里的文字，
  不再依赖正文里的第一个标题
- **一个文件里放多章**（如《双城记》）：按目录锚点把文档拆成多章，部标题页会自动跳过
- **按「部」分组**：目录里显示 `第一部 复活` / `第二部 金线` 这样的分组头，同名章节不再混淆
- **圈号注释**：支持 `① ② ⑩` 这类序号，正文里变成可点击角标，朗读时自动跳过；
  整组注释挤在同一段里也能拆开

### 阅读跟随

设置 →「跟随朗读」：

- **高亮当前段落**：关掉后只朗读、不标记（改成一个不起眼的下边框）
- **自动滚动跟随**：关掉后完全由你自己滚动页面
- **段落首行落在视口 80%**（30%–90% 可调），不再居中跳来跳去

### 生成面板可收起

生成面板点 ✕ 收起后会变成一个悬浮小胶囊（右下角，显示 `生成中 12/58`），
点它随时把面板叫回来；生成结束或出错也会保留提示。

## 批量生成与生成队列

### 目录多选

左侧「目录」标签页点「多选」，每个章节前会出现复选框：

- 只生成**尚未生成**的段落（已生成的自动跳过，底部条会提示「已选 N 章 · M 段待生成」）
- 「选未生成」一键勾选所有还有待生成段落的章节
- 「生成选中」把这些章节排进队列（生成中也不会被打断）

### 生成队列

生成不再"一次只能跑一个"：

- 生成进行中，顶栏按钮会变成「**加入队列**」，点它把当前章节排到队尾
- 面板里会显示「队列中还有 N 个任务」，可随时「清空」
- 当前任务结束后自动接着跑队列里的下一个
- 点「停止」会同时清空队列

## 存储压缩（Opus）

生成时自动把 Voicebox 输出的 WAV 交给本地服务端，用 ffmpeg 转成 **Opus/WebM** 再存进浏览器：

- 24kbps 单声道，语音质量足够，体积约为 WAV 的 **1/10 ~ 1/20**
- 设置里可关（「存储 → 压缩音频」）；服务端找不到 ffmpeg 时自动退回 WAV，不影响使用
- 已存在的 WAV 音频不受影响（播放器两种格式都支持）
- 想换 ffmpeg 路径：`set FFMPEG_PATH=D:\path\to\ffmpeg.exe`

> 实测：Voicebox 的 24kHz WAV 约 211KB/4.4 秒 → 压缩后 4KB，短句压缩比更夸张，长音频稳定在 10~16 倍。

## 阅读侧增强

- **行距 / 段距**：设置里两个滑块，实时生效
- **自动夜间**：19:00–07:00 自动切夜读主题，白天恢复你选的
- **全文搜索**：目录页顶部搜索框，跨章节搜索，结果显示章节名 + 上下文片段，点一下跳到那一段
- **书签与批注**：正文里右键 →「添加书签」/「写批注…」；右栏新增「笔记」分页，列出本章所有书签与批注，点击跳回原文，可直接删除
- 有标记的段落正文里会带一条下划线，方便回头找

## 数据迁移

设置 →「数据」：

- **导出备份**：把全部书籍、章节、笔记、阅读进度和音频打成一个 zip（流式打包，不整块占内存）
- **导入备份**：选择 zip 恢复；同 ID 的书会覆盖，其余书不受影响
- 备份也可以在别的电脑/浏览器导入，用于换机或版本升级前留底

### 搜索可用性

- 搜索条固定在目录顶部，**输入时不会被打断**（以前每敲一个字侧栏就整块重建）
- 右侧 ✕ 或 **Esc** 一键退出搜索，回到章节列表
- 点搜索结果跳到对应段落时，搜索结果不会消失，可以接着点下一条
- 切换书籍会自动清空搜索

### 旧音频瘦身

设置 →「数据 → 压缩已有音频」：把之前保存的 **WAV 逐段转成 Opus**，体积约为原来的 1/10。

- 先扫描统计有多少段、占多少空间，确认后再开始
- 逐段转码、实时进度；中途可以点「停止压缩」，已完成的保留
- 只是替换音频数据，段号、key、播放进度都不受影响
- 已经压缩过的段落会自动跳过

### 音色档案重建（id 变化）

在 Voicebox 里删掉音色再重建，profile id 会变，但声音其实是同一个。现在会区分两种情况：

| 情况 | 判断依据 | 提示 | 处理 |
| --- | --- | --- | --- |
| **档案失效** | 音频记录的 profileId 已不在当前音色列表里 | `N 段音色档案已失效 · 更新标记` | 「只更新标记」——不重新合成，瞬间完成 |
| **真的换了音色** | 两个档案都存在但不同 | `N 段音色不一致 · 处理` | 重生成，或手动更新标记 |

入口：

- 章节头的提示按钮 →「只更新标记 / 重新生成本章 / 全书都更新标记」
- 顶栏「音色」菜单 →「以当前音色重标记本章 / 全书」

重标记只改 `meta`（音色 id、引擎、模型、语言），音频数据、段号、播放进度都不动。

### 诗行行号标注

有些诗体版本会在每 5 行的行末带一个行号（如 `……离开那漂亮的车子， 245`）。现在会自动识别：**行号照常显示（行末小号数字），但不会被朗读**。

判定不是"看到行末数字就删"（那会误伤正文，比如"他数到 20"），而是看**整章的数字序列**：

- 至少 3 处行末数字
- 相邻数字的步长有稳定众数（这类书通常是 5）
- 众数要覆盖 60% 以上

命中后把数字从**朗读文本**里去掉，同时记录到 `block.lineNo`，阅读时在行末以小号数字显示（鼠标悬停提示「原书第 N 行」）。

已经导入过的书，**下次打开章节会自动补做这一步**（行号会立刻显示出来）。如果该章已经生成过音频，声音里的行号需要重新生成才会消失。
